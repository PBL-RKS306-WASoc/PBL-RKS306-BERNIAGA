# BERNIAGA (Sistem Deteksi dan Respons Keamanan Siber untuk Transaksi E-commerce)

Repository PBLRKS-306 yang berjudul BERNIAGA (Sistem Deteksi dan Respons Keamanan Siber untuk Transaksi E-commerce). Proyek ini melibatkan 5 mata kuliah pada semester 3 ini dengan pembagian tanggung jawab per lapisan sistem:
- Internetworking (segmentasi jaringan dan firewall inti)
- Network Defender Essentials (NIDS/NIPS, WAF, hardening jaringan)
- Web Fundamental (server web, aplikasi, autentikasi dan target uji)
- DevOps (otomasi penggelaran dan pencadangan)
- SOC Essentials (pengumpulan log, deteksi, triase, threat intelligence, respons insiden, notifikasi, Rule Based Access Control platform SOC)
